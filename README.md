# Mesa Launcher — лаунчер для Android TV / Google TV в стиле macOS

Рассчитан на TCL Smart TV Pro с Android TV 11 (API 30), но работает на любом Android TV 8.0+.

## Что внутри

- **Строка меню** сверху: значок слева открывает «Об этом ТВ», значок справа — настройки системы, статус сети, часы.
- **Dock** внизу: иконки приложений в виде «скруглённых квадратов», при наведении фокуса увеличиваются (эффект как в macOS), над ними всплывает подпись.
- **Launchpad** (первая иконка Dock): сетка всех установленных приложений.
- **Виджеты** справа: часы и календарь.
- **Окно «Об этом ТВ»** с данными вашего телевизора (читаются с самого устройства).
- Собственные обои, нарисованные кодом, и «матовое стекло» вместо реального размытия (на Android 11 настоящий blur недоступен).

## Управление пультом

| Действие | Кнопка |
|---|---|
| Перемещение | стрелки |
| Открыть приложение / окно | OK |
| Убрать приложение из Dock | удержание OK на иконке в Dock |
| Закрепить / открепить в Dock | удержание OK на иконке в Launchpad |
| Закрыть Launchpad или окно | Назад |
| Вернуться на рабочий стол | Home |

## Сборка APK

Нужен один из вариантов.

**1. Android Studio (проще всего).** File → Open → выберите эту папку, дождитесь синхронизации Gradle (нужен интернет),
затем Build → Build Bundle(s) / APK(s) → Build APK(s). Готовый файл:
`app/build/outputs/apk/debug/app-debug.apk`.

**2. Командная строка.** Нужны JDK 17+ и Android SDK (платформа 34). Укажите путь к SDK в `local.properties`
(`sdk.dir=/путь/к/Android/Sdk`), затем:

```
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug
```

**3. Без установки Android Studio — через GitHub.** Загрузите папку в новый репозиторий GitHub, откройте
Actions → «Build APK» → Run workflow, после сборки скачайте `mesa-launcher-apk` из Artifacts.

## Установка на телевизор

1. На ТВ: Настройки → Настройки устройства → О ТВ → семь раз нажмите на «Сборка» (включится режим разработчика).
2. Настройки устройства → Для разработчиков → включите «Отладку по USB» (если есть пункт «Отладка по Wi-Fi» —
   используйте его вместе с `adb pair`).
3. На компьютере (нужен [adb](https://developer.android.com/tools/releases/platform-tools)), ТВ и компьютер в одной сети:

```
adb connect 192.168.X.X:5555        # IP телевизора: Настройки → Сеть
adb install -r app-debug.apk
```

На экране ТВ подтвердите доступ отладки. После установки «Mesa Launcher» появится в списке приложений.

## Как сделать лаунчер основным (кнопка Home)

1. Запустите Mesa Launcher из списка приложений и убедитесь, что он открывается.
2. Нажмите Home. Если ТВ спросит, какое приложение использовать как домашний экран, выберите Mesa Launcher → «Всегда».
3. Если не спросил — назначьте через ADB. Сначала **запишите** текущий (штатный) лаунчер, он нужен для отката:

```
adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell cmd package set-home-activity --user 0 com.mesa.launcher/.MainActivity
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

   Последняя команда должна показать `com.mesa.launcher/.MainActivity`.
   **Откат:** `adb shell cmd package set-home-activity --user 0 <записанный компонент>`.
4. Если Home всё равно открывает штатный экран (на части прошивок кнопка перехватывается системой) — поставьте из
   Play Маркета приложение «Button Mapper» и назначьте на Home запуск Mesa Launcher.
5. Крайняя мера, на свой риск: отключить штатный лаунчер `adb shell pm disable-user --user 0 <пакет>`
   (пакет — часть до `/` из шага 3; обычно `com.google.android.tvlauncher` или `com.google.android.apps.tv.launcherx`).
   Не делайте этого, пока Mesa не открывается по Home. Откат: `adb shell pm enable <пакет>`. На Google TV для этого
   способа иногда приходится отключать ещё и `com.google.android.tungsten.setupwraith`.
   Универсальный сброс — сброс ТВ к заводским настройкам, но до него лучше не доводить.

## Настройка под себя

| Что | Где |
|---|---|
| Какие приложения закреплены по умолчанию, размер Dock | `AppRepository.kt` → `DEFAULT_PACKAGES`, `MAX_DOCK` |
| Обои | `ui/Wallpaper.kt` (рисуются кодом: градиент и «волны») |
| Масштаб интерфейса | `ui/Theme.kt` → `DESIGN_WIDTH_DP` (интерфейс рисуется на виртуальном экране 1280 dp) |
| Виджеты | `ui/Widgets.kt` |
| Окно «Об этом ТВ» | `ui/AboutDialog.kt`, данные — `data/DeviceInfo.kt` |

## Ограничения

- Настоящего размытия фона нет (Android 11): «стекло» имитировано полупрозрачными слоями.
- Пункты «Файл», «Правка», «Вид» и т. д. в строке меню — только оформление.
- Нет индикаторов «приложение запущено» под иконками Dock: Android не отдаёт обычным приложениям список запущенных.
- Обои — нарисованные кодом; выбор собственной картинки пока не реализован.

## Статус проверки

Проект написан и проверен статически (синтаксис Kotlin, импорты, XML ресурсов). Полную сборку и запуск на телевизоре
нужно выполнить у себя: в среде разработки не было Android SDK. Если сборка выдаст ошибку, пришлите текст ошибки — поправим.
